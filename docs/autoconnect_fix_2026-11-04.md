# Автоподключение: исправление 04.11.2026

## Наблюдение

В актуальном `target/release/btf.log` в 13:14:29 и 13:15:27 появлялся
`link UP`, но endpoint наушников отсутствовал: keepalive открывал WAVE_MAPPER,
а спустя один 20-секундный опрос журнал показывал `link DOWN` с нулём ошибок
рендера. В 13:16:17 появился целевой endpoint #2. Отдельный read-only запрос
Win32 подтвердил подключённые Redmi Buds 6 Lite и их waveOut endpoint.
Это подтверждает ложный критерий готовности; точную причину каждого разрыва
на воздухе без нового ETW-захвата установить нельзя.

## Изменения

- Первая исходящая попытка соединения — на первом disconnected-опросе,
  следующие — по 10-секундному таймеру вместо минуты. Вызов ограничен 5 с;
  блокирующее восстановление драйвера по-прежнему может увеличить задержку.
- Keepalive не открывает системный default вместо наушников. При отсутствии
  целевого endpoint список повторно проверяется с интервалом 1–5 с.
- Готовность подтверждается только после успешной постановки буфера в
  целевой waveOut. Это локальная проверка, не доказательство звука на воздухе.
- Пока аудио не готово, polling остаётся быстрым, эпизод не закрывается,
  socket hold не освобождается и счётчик неудачных восстановлений не сбрасывается.
- Транспорт без аудио получает 20 с на появление endpoint, затем продолжает
  ограниченное восстановление профиля, не останавливая его поиск. Сбросы
  радио и PnP-эскалация разрешены только при отключённом транспорте.
- После успешного paging 3-секундное settle-окно защищает все fallback-ступени;
  аварийное восстановление отключённого драйвера/радио имеет приоритет.
- Исправлено соответствие waveOut ID при пропуске устройства с ошибкой caps.

## Проверка

`cargo test` и `cargo test --manifest-path poc/Cargo.toml`.
Регрессии проверяют транспорт без аудио, первую/повторную попытку paging и
защиту settle-окна. Старые PoC модели toggling не доказывают реальный paging.

Полевая приёмка: закрыть кейс до разрыва → открыть рядом с ПК, не нажимая
«Подключить» → дождаться `audio READY` и проверить звук. Повторить после сна.
